# Bangalore Journey Planner

A web-based journey planner for finding bus routes in Bangalore.

## 🚧 Project Status

This project is currently under development.

## Features

- Find routes between bus stops
- Find direct bus routes
- Find routes with fewer bus changes
- Calculate journey time and fare
- Compare routes based on different criteria

## Technologies

- HTML
- CSS
- JavaScript
- Graph algorithms
- BFS
- Dijkstra's algorithm

## Algorithms

The project uses graph-based route-finding algorithms to explore different journey options, including:

- **BFS** for finding routes with fewer bus changes
- **Dijkstra's algorithm** for route optimization based on criteria such as fare and journey time
